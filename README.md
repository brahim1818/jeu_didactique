# 🐱 Cat to Cheese — Educational Programming Game

An interactive educational game designed to introduce students to **programming fundamentals** through visual logic and problem-solving.


## 📌 Overview

**Cat to Cheese** is a browser-based serious game where learners guide a cat through a grid-based maze to reach cheese using block-based programming logic.

The game teaches core programming concepts in a progressive and interactive way:

* Sequential execution
* Loops (repetition)
* Conditional statements
* While loops (advanced logic)

---

## 🎯 Educational Objectives

By playing this game, students will:

* Understand how **algorithms are structured**
* Learn the concept of **step-by-step instructions**
* Use **loops to optimize code**
* Apply **conditions to solve dynamic problems**
* Develop **logical thinking and debugging skills**

---

## 🎮 Game Features

* 🧩 Drag & drop block-based programming interface
* 🧠 Three progressive difficulty levels
* 🗺 Interactive grid-based environment
* 🐱 Animated execution of instructions
* 🧾 Real-time pseudo-code generation
* ⭐ Performance scoring system (efficiency-based)
* ⚡ Adjustable execution speed

---

## 📚 Levels Description

### Level 1 — Sequence

Learn basic programming by giving step-by-step movement instructions to the cat.

### Level 2 — Loops

Introduce repetition to reduce the number of blocks and optimize solutions.

### Level 3 — Conditions & While Loops

Solve dynamic mazes using conditional logic and advanced control structures.

---

## 🧪 How to Play

1. Drag blocks from the toolbox into the workspace
2. Arrange them to build your program
3. Click **Run ▶** to execute the instructions
4. Guide the cat 🐱 to the cheese 🧀
5. Optimize your solution to earn more stars ⭐

---

## 🛠 Tech Stack
